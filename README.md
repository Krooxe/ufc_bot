# 🥊 UFC Betting Game Bot (Telegram)

> **Статус:** Проект в активной разработке / рабочий прототип  
> **Назначение:** Частный Telegram-бот для игры в ставки на турниры UFC  
> **Важно:** Бот предназначен для развлекательных целей, без реальных денежных ставок

---

## 🧠 Идея проекта

UFC Betting Game Bot — это игровая система ставок на турниры UFC в Telegram.

Основные принципы:
- ставки делаются на **реальные бои в номерных турнирах UFC**
- очки начисляются **за угаданные бои**
- предусмотрена **1 страховочная ставка** на случай отмены боя
- турниры полностью управляются через **админ-панель**

Проект рассчитан на небольшое количество пользователей (приватное использование).

### 🧩 Архитектура

Проект построен по **модульному принципу** с чётким разделением на три слоя:

```
bot.py              ← Точка входа, регистрирует все роутеры
│
├── handlers/       ← UI-слой: всё взаимодействие с Telegram
├── services/       ← Бизнес-логика: операции с базой данных  
└── api/            ← Внешние данные: парсинг UFCStats.com
```

**Корневые файлы:**
- **bot.py** — точка входа (85 строк), только регистрирует роутеры
- **database.py** — ORM-модели: User, Event, Fight, Bet, Setting, FightResult
- **db_utils.py** — маршрутизатор → `services/` (обратная совместимость)
- **ufc_api.py** — маршрутизатор → `api/` (обратная совместимость)
- **config.py** — настройки, токены, DEBUG_MODE

> `db_utils.py` и `ufc_api.py` логики не содержат — только реэкспортируют функции из модулей. Это позволяет использовать как старые импорты (`from db_utils import ...`), так и новые (`from services import ...`).

**Структура модулей:**

```
handlers/               ~ 2400 строк, UI-логика
├── commands.py         — /start, /help, /admin
├── menu.py             — главное меню пользователя
├── admin.py            — админ-панель
├── odds_input.py       — ввод коэффициентов (FSM)
├── archive.py          — архив и рейтинг
├── announcements.py    — рассылки
└── bets/               — модуль ставок
    ├── selection.py    — выбор боёв
    ├── winners.py      — выбор победителей
    ├── insurance.py    — страховая ставка
    ├── save.py         — сохранение
    └── view.py         — просмотр ставок

services/               ~ 810 строк, бизнес-логика
├── session.py          — управление сессиями БД
├── event_service.py    — операции с турнирами
├── fight_service.py    — операции с боями
├── user_service.py     — операции с пользователями
├── bet_service.py      — операции со ставками
├── results_service.py  — расчёт очков и результатов
└── settings_service.py — настройки приложения

api/                    ~ 530 строк, внешние данные
├── events.py           — получение турниров с UFCStats.com
├── fights.py           — парсинг боёв
├── results.py          — получение результатов
└── test_data.py        — тестовые данные (DEBUG_MODE)
```

Архитектура ориентирована на:
- асинхронную работу
- минимальное дублирование логики
- расширяемость проекта
