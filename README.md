# 🥊 UFC Betting Game Bot (Telegram)

> **Статус:** Проект в активной разработке / рабочий прототип  
> **Назначение:** Частный Telegram-бот для игры в ставки на турниры UFC  
> **Важно:** Бот предназначен для развлекательных целей, без реальных денежных ставок

---

## 🧠 Идея проекта

UFC Betting Game Bot — это игровая система ставок на турниры UFC в Telegram.

Основные принципы:
- ставки делаются **реальные бои в номерных турнирах UFC**
- очки начисляются **за угаданные бои**
- предусмотрена **1 страховочная ставка** на случай отмены боя
- турниры полностью управляются через **админ-панель**

Проект рассчитан на небольшое количество пользователей (приватное использование).

---

## 🧱 Стек и архитектура проекта

### ⚙️ Технологический стек
- **Язык:** Python 3.x
- **Telegram API:** aiogram 3.x
- **База данных:** SQLite (на текущем этапе)
- **ORM:** SQLAlchemy (async)
- **HTTP:** aiohttp
- **Асинхронность:** asyncio
- **Логирование:** logging
- **Конфигурация:** .env / config.py

---

### 🧩 Архитектура
Проект построен по модульному принципу с разделением ответственности:

- **bot.py** — точка входа, команды, inline-кнопки, FSM
- **database.py** — модели БД и инициализация
- **db_utils.py** — бизнес-логика и операции с БД
- **ufc_api.py** — UFC / ESPN API + fallback + тестовые данные
- **config.py** — конфигурации
- **temp storage** — временные данные администратора
- **FSM** — ввод коэффициентов, результатов, объявлений

Архитектура ориентирована на:
- асинхронную работу
- минимальное дублирование логики
- расширяемость проекта
