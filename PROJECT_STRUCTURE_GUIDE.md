# 📚 UFC Bot - Структура проекта (Шпаргалка)

## 🎯 Корневые файлы

### bot.py (85 строк)
**Точка входа приложения**
- Запускает бота
- Регистрирует все роутеры из handlers/
- МАРШРУТИЗАТОР → handlers/

### database.py (132 строки)
**Модели базы данных (SQLAlchemy ORM)**
- Классы: User, Event, Fight, Bet, Setting, FightResult
- Описывает структуру таблиц БД
- НЕ ТРОГАТЬ - это правильное место!

### db_utils.py (18 строк)
**МАРШРУТИЗАТОР → services/**
- Реэкспортирует все функции из services/
- Для обратной совместимости со старым кодом
- Сам логики НЕ содержит

### ufc_api.py (15 строк)
**МАРШРУТИЗАТОР → api/**
- Реэкспортирует все функции из api/
- Для обратной совместимости
- Сам логики НЕ содержит

## 🔧 services/ - Бизнес-логика БД (~810 строк)

### event_service.py (327 строк)
**Работа с турнирами**
- Создание, получение, обновление событий

### fight_service.py
**Работа с боями**

### bet_service.py
**Работа со ставками**
- get_user_bets_for_event() - ставки пользователя

### results_service.py
**Расчёт результатов и очков**

- calculate_points_for_event() - очки для всех

### settings_service.py
**Настройки приложения**

## 📊 Архитектура проекта

```
┌─────────────┐
│   bot.py    │ ← Точка входа
└──────┬──────┘
       │
       ├──→ handlers/ ────────────┐
       │    (UI логика)           │
       │                          ▼
       │                    services/ ───→ database.py
       │                    (БД логика)   (ORM модели)
       │
       └──→ api/ ─────────────────→ UFCStats.com
            (Парсинг турниров)
```

## 🎯 Ключевые принципы:

### 1. Модульность
- Каждый файл < 330 строк
- Один файл = одна ответственность

### 2. Маршрутизаторы
- bot.py → handlers/
- db_utils.py → services/
- ufc_api.py → api/

### 3. Разделение слоёв
- **handlers/** - UI (работа с Telegram)
- **services/** - бизнес-логика (БД)
- **api/** - внешние API (парсинг)

### 4. Обратная совместимость
- Старые импорты работают:
  ```python
  from db_utils import get_session  # ✅
  from services import get_session  # ✅ тоже работает
  ```

## 🚀 Быстрый старт

### Запуск бота:
```bash
python bot.py
```

### Режимы работы:
```python
# config.py
DEBUG_MODE = True   # → ufc_bot_test.db (тест)
DEBUG_MODE = False  # → ufc_bot.db (прод)
```

### Структура импортов:
```python
# UI логика
from handlers import commands, menu, admin

# БД логика
from services import get_session, get_event_by_id
# или
from db_utils import get_session  # старый стиль

# API логика  
from api import get_next_ppv_event
# или
from ufc_api import get_next_ppv_event  # старый стиль
```

## 🎉 Итого

**Весь код организован в 3 слоя:**
1. **handlers/** - что видит пользователь (UI)
2. **services/** - что происходит с данными (БД)
3. **api/** - откуда берутся данные (внешние источники)

**Всё чисто, модульно и понятно! 🔥**
